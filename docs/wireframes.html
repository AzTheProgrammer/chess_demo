6. Cross-surface flows

Primary loop

Home ──► Play ──► [game over] ──► Analyze
  │                              ▲
  └──► Recent game tap ──────────┘

Train hub ──► Openings / Tactics / Squares ──► (board surfaces)

Navigation IA

  • Bottom nav always visible (Jakob's Law — familiar 5-tab pattern)
  • Train sub-routes push onto stack; back returns to hub
  • Play → Analyze passes PGN via route extra (no re-import friction)
